Speichern

Status, Notizen und deine Einschätzungen landen in data/progress.json in deinem GitHub-Repo. So hast du auf Handy und Laptop denselben Stand. Kostet nichts.

  1. Auf GitHub: Settings → Developer settings → Fine-grained tokens → Generate new token.
  2. Nur dieses Repo auswählen, Berechtigung Contents: Read and write.
  3. Token hier einfügen. Er bleibt nur in diesem Browser gespeichert.

Backup ohne GitHub: Fortschritt als Datei sichern oder auf ein anderes Gerät übertragen.
